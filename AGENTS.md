# Instructions for AI coding agents

This file is read by Codex, Cursor and other agents. `CLAUDE.md` carries the same text for Claude Code.

- **No AI attribution in git.** Commits and pull requests are authored by the person making them. Never add a `Co-Authored-By` trailer, a "Generated with" line, or any other credit to an AI tool (Claude, Codex, Copilot, Cursor or anything else) to a commit message or a pull request description.
- Everything else about working in this repository is in `CONTRIBUTING.md`.
